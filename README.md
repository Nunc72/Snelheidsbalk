# VeloVerde

Testapp (PWA) voor een navigatiescherm met een gekleurde snelheidsbalk bovenin.
De kleur geeft aan hoe hard je rijdt ten opzichte van de maximumsnelheid; rechts staat het verkeersbord.

- Kaart: MapLibre GL JS + OpenFreeMap (OpenStreetMap-data)
- Route, afslag-instructies en maximumsnelheid: Valhalla (valhalla1.openstreetmap.de)
- Zoeken: Photon (photon.komoot.io)

Live: https://nunc72.github.io/Snelheidsbalk/
Demo zonder GPS (rijdt zelf over de route): https://nunc72.github.io/Snelheidsbalk/?demo=1

Geen build-stap: index.html, style.css en app.js worden direct geserveerd.
